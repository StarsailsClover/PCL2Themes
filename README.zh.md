# PCL2Themes

> 面向 **官方版 PCL2** 的主题 / UI 自定义 / 媒体增强模块，以 `PCL2Swap` 的 `.swapaddon` 形态分发。

PCL2Themes 把官方启动器里原本封闭的主题能力变成可用的模块平台：解锁官方内置的赞助主题、
补充我们自己的主题预设、提供实时主题编辑器（色相 / 饱和度 / 明度 / 顶栏渐变偏移），并扩展
亚克力材质、视频背景、自定义字体与带歌词的音乐播放体验。

模块**只面向官方版 PCL2**（CE 不在范围内），运行在 `PCL2.dl.swap` 运行时之上（注入形状与磁盘
补丁形状），通过公开的 `PCL2Swap.Api` 1.0 SDK 接入。
